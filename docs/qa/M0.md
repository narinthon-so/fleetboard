## Defect Summary

One major defect was identified during test execution:

1. **CLI commands taking freeform / markdown text fail when value starts with a hyphen (`-`)**
   - **Severity**: Major (Severity 1)
   - **Affected commands**: `fb add --ac`, `fb add --goal`, `fb plan <id> <text>`, `fb note <id> <text>`, `fb done <id> --result <text>`, `fb reject <id> <comment>`
   - **Root cause**: Missing `allow_hyphen_values = true` on clap arguments. Clap parses leading `-` (standard for markdown checklists `- [ ]` and bullet lists `- item`) as an unknown option switch.
   - **Impact**: Breaks standard agent and human workflows when passing markdown checklists or bullet points directly on the command line.
