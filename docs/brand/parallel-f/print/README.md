# Print reference artwork

These PDFs contain vector paths and RGB colours. They scale without rasterisation.
They are reference artwork, not certified PDF/X or press-profiled CMYK files.

Ask the printer to convert using the output ICC profile for the specific stock and
process, and approve a physical proof. Use 100 K for the black-only version rather
than an automatic rich-black mix. White files have transparent backgrounds and
represent white ink or reversed artwork; show the printer the intended substrate.
Spot colours/Pantone matches have not been assigned. The usage guide's CMYK
percentages are mathematical estimates, not a production colour specification.
